# AI Engineering Labs

Los scripts pequeños del curso se consolidan aquí por concepto. El objetivo es poder volver meses después y recordar **qué problema resuelve cada patrón**, sin confundir ejercicios con productos.

- `01-tools`: contrato de herramienta y ejecución.
- `02-langgraph`: estado, nodos y routing.
- `03-memory`: memoria de sesión y persistencia conceptual.
- `04-rag`: retrieve → context → generate.
